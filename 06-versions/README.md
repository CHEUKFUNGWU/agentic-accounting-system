# Versions

Create one `v<major>.<minor>/` directory per planned version. Maintain its goals, committed scope in `scope.md`, and milestones. A target version in the requirement pool is a plan; the version scope records the commitment.

The [draft roadmap](../03-planning/product-roadmap.md) proposes version sequencing. No version scope is committed by that draft. Create the corresponding scope record after owner approval of concrete requirements and milestones.
