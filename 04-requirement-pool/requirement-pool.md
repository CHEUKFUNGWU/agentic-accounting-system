## Field rules

- Sources contain source IDs such as `SRC-XXXX`, linked to the source register or supporting input.
- Status uses the definitions in [status-and-gates.md](../00-rules/status-and-gates.md). This table is the only maintained location for current requirement status. Link status decisions and gate evidence in the status cell.
- Priority uses `P0`, `P1`, `P2`, or `P3`, with a short rationale in the cell or a link to the work package's rationale. Do not assign priority without evidence.
- Owner names the accountable person. Use `To confirm` for unresolved fields instead of inventing assignments or commitments.
- Target version represents the current plan. Committed scope is maintained in `06-versions/<version>/scope.md`.
- Dependencies reference requirement IDs or documented external dependencies.
- Work package links to `05-requirements/req-XXXX-short-name/README.md` when one exists; otherwise use `Not created`.
