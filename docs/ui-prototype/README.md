# Agentic Accounting UI prototype

這是一個供會計人員試用的高保真互動原型，主線為單據覆核與月結，支援繁體中文和英文。它使用獨立入口，不替換現有 app.html，也不呼叫後端寫入帳目。

## 開啟

在 frontend 執行 `npm run dev:web -- --host 127.0.0.1`，開啟 http://127.0.0.1:5173/prototype.html 。正式編譯使用 `npm run build:web`，輸出包含 dist/prototype.html。

## 建議試用路徑

1. 工作台點選 Telstra。把業務比例由 80% 調整到 85%，借方會更新為通訊費 102.00、GST 10.20、董事往來 19.80，貸方為應付帳款 132.00。勾選確認後核准。
2. 開啟 Studio North。核准按鈕因疑似重複而停用，選擇退回並輸入原因。
3. 核准 Figma。開啟 Dell，確認電腦設備分類後核准。
4. 在會計分錄查看三筆分錄，借貸各合計 AUD 3,080.00，並下載 CSV。
5. 前往月結工作區。確認示範銀行對帳後，簽核並鎖定本期。重新整理後，狀態仍保留。
6. 切換三大報表、查看 Agent 操作紀錄，或從頁尾重設示範。

右上角 EN / 繁中切換語言。搜尋按鈕或 Cmd/Ctrl+K 可搜尋供應商、單據編號與頁面。手機導覽由左上選單開啟。

## 畫面與互動

- 工作台：待辦、審核進度、月結下一步、最近活動及固定示範財務摘要。
- 審核中心：按狀態篩選、搜尋、原始憑證與建議分錄並排、拆分比例、確認、退回原因及證據紀錄。
- 會計分錄：本次核准項目、借貸對照、回到憑證、CSV 匯出。
- 月結工作區：前置條件、人工確認、簽核確認及唯讀狀態。
- 財務報表：損益表、資產負債表、現金流量表與列印樣式。
- Agent 活動：角色權限與人員操作紀錄。

## 原型邊界

所有單據、發票內容與財務數字均為合成示範。原型採用既有示例公司 Spark AI Studio Pty Ltd，期間固定為 2026 年 10 月，幣別為 AUD。公司與期間沒有假切換操作。

財務摘要與報表是固定、相互勾稽的樣本，**不會隨核准操作重新計算**。核准項目獨立顯示於會計分錄。公私拆分的 GST 僅展示數字與版面關聯，並非稅務判定引擎。匯入功能只預覽本機檔名並檢查類型與大小，不傳送檔案、不進行 OCR。

進度儲存在瀏覽器 localStorage 的 `aas-review-prototype-v1`，語言儲存在 `aas-prototype-language`。頁尾的「重設示範」只重設這個原型的進度。
